# Τα Οικονομικά μου

Ιδιωτική εφαρμογή για budget και έξοδα, για iPhone και web (PWA). Τα δεδομένα μένουν **μόνο στη συσκευή**: δεν υπάρχει server, λογαριασμός, analytics ή tracking.

## Δυνατότητες

- **Budget** ημερήσιο, εβδομαδιαίο, μηνιαίο και ετήσιο, και μηνιαίο budget ανά κατηγορία. Η αρχική οθόνη δείχνει πόσα **μπορείς να ξοδέψεις σήμερα**, με βάση το πιο αυστηρό budget.
- **Αγορές προϊόν-προϊόν**, με τιμή και κατηγορία για το καθένα. Θυμάται προϊόντα και καταστήματα που έχεις ξαναγράψει.
- **Μοίρασμα σε ημέρες**: π.χ. φαγητό για 3 ημέρες μετράει το 1/3 του κόστους σε κάθε ημέρα.
- **Στατιστικά** ανά εβδομάδα, μήνα και έτος: ανά κατηγορία, κορυφαία προϊόντα, σύγκριση με την προηγούμενη περίοδο. Προβολή «Κατανάλωση» (με το μοίρασμα) ή «Πληρωμές» (την ημέρα που πλήρωσες).
- **Apple Pay** μέσω αυτοματισμού στις Συντομεύσεις (οδηγίες μέσα στις Ρυθμίσεις).
- **Διατροφή** (iPhone): γεύματα με θερμίδες και macros, βιβλιοθήκη τροφίμων, «μπορείς να φας σήμερα», κόστος ανά 1.000 kcal. Με την εφαρμογή **Υγεία** ο στόχος ακολουθεί το ρολόι (θερμίδες ηρεμίας + κίνησης) και φαίνονται βήματα, ύπνος, παλμοί και βάρος. Προαιρετικά **εκτίμηση θερμίδων από φωτογραφία**.
- Λειτουργεί **offline** και ενημερώνεται αυτόματα.

## Ασφάλεια

| Μέτρο | Λεπτομέρειες |
|---|---|
| Τοπική αποθήκευση | IndexedDB στη συσκευή. Καμία αποστολή δεδομένων πουθενά. |
| Φωτογραφίες φαγητού (προαιρετικό) | Μόνο αν το ενεργοποιήσεις: η φωτογραφία περνά από τον δικό σου server στο Claude API (Anthropic) για εκτίμηση θερμίδων και δεν αποθηκεύεται. Τα δεδομένα της Υγείας δεν φεύγουν από το iPhone. |
| Κρυπτογράφηση (προαιρετική) | AES-256-GCM. Το κλειδί παράγεται από τον κωδικό με PBKDF2-SHA-256 (600.000 επαναλήψεις) και τυχαίο salt. Το κλειδί δεν αποθηκεύεται ποτέ. |
| Κλείδωμα | Αυτόματο κλείδωμα όταν φεύγεις από την εφαρμογή (ρυθμίζεται). Μετά από 5 λάθος κωδικούς, αυξανόμενη αναμονή έως 15 λεπτά. |
| Content-Security-Policy | `default-src 'none'`: μόνο αρχεία της ίδιας της εφαρμογής, χωρίς inline scripts ή styles και χωρίς συνδέσεις σε τρίτους. |
| Καμία εξάρτηση | Μηδέν εξωτερικές βιβλιοθήκες, άρα κανένας κίνδυνος από supply chain. |
| Επικύρωση δεδομένων | Τα αντίγραφα που εισάγονται ξαναχτίζονται πεδίο-πεδίο και όλο το κείμενο γίνεται escape πριν εμφανιστεί (προστασία από XSS). |
| Αντίγραφα ασφαλείας | Αν έχεις κωδικό, η εξαγωγή είναι κρυπτογραφημένη με αυτόν. |

> ⚠️ Αν ξεχάσεις τον κωδικό, τα κρυπτογραφημένα δεδομένα **δεν ανακτώνται**. Κράτα αντίγραφα ασφαλείας.

## Εγκατάσταση στο iPhone

1. Άνοιξε τη διεύθυνση της εφαρμογής στο **Safari**.
2. Πάτα **Κοινοποίηση** και μετά **«Προσθήκη στην οθόνη Αφετηρίας»**.

Ως εγκατεστημένη εφαρμογή ανοίγει σε πλήρη οθόνη και το iOS δεν σβήνει τα δεδομένα της όσο δεν τη χρησιμοποιείς.

## Ανάπτυξη

```sh
npm start        # http://localhost:8080
npm test         # unit tests της λογικής (Node 20+)
```

Δεν υπάρχει βήμα build: τα αρχεία σερβίρονται όπως είναι, π.χ. μέσω GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

### Νέα έκδοση

```sh
npm run release -- 1.1.0
```

Η εντολή αλλάζει την έκδοση στα `sw.js`, `js/version.js` και `package.json`. Μόλις ανέβει, όσοι έχουν την εφαρμογή βλέπουν «Υπάρχει νέα έκδοση → Ενημέρωση». Τα δεδομένα τους δεν επηρεάζονται, και οι αλλαγές στη μορφή τους περνάνε από το `sanitize()` στο `js/app.js`.
