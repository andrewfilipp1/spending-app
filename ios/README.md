# Οικονομικά για iPhone

Native εφαρμογή iOS (SwiftUI, iOS 17+), με τα ίδια δεδομένα και αντίγραφα ασφαλείας με την web έκδοση.

## Τι προσθέτει σε σχέση με την web έκδοση

- **Ειδοποιήσεις** (τοπικές, χωρίς server): καθημερινή υπενθύμιση, 80%/100% ενός budget, υπέρβαση του σημερινού ορίου.
- **Κλείδωμα με Face ID**, και απόκρυψη των ποσών στην εναλλαγή εφαρμογών.
- **Apple Pay αυτόματα**: η ενέργεια «Καταχώρηση πληρωμής» στις Συντομεύσεις, μαζί με τον αυτοματισμό «Συναλλαγή», καταγράφει κάθε πληρωμή χωρίς να ανοίξεις την εφαρμογή.
- Τα δεδομένα κρυπτογραφούνται από το iOS (Data Protection) και η εφαρμογή δεν συνδέεται ποτέ στο internet.

## Εγκατάσταση χωρίς App Store (δωρεάν Apple ID)

Το iPhone δέχεται μόνο εφαρμογές υπογεγραμμένες από την Apple. Με δωρεάν Apple ID η υπογραφή ισχύει **7 ημέρες** και μετά ανανεώνεται. Τα δεδομένα δεν χάνονται στην ανανέωση.

### Α. Με AltStore (χωρίς Xcode, αυτόματη ανανέωση)
1. Κατέβασε το `Oikonomika.ipa` από τα [Releases](https://github.com/andrewfilipp1/spending-app/releases).
2. Εγκατάστησε το **AltServer** στο Mac από το altstore.io και, από εκεί, το **AltStore** στο iPhone (με καλώδιο, με το Apple ID σου).
3. Στο iPhone: **Ρυθμίσεις → Απόρρητο & ασφάλεια → Λειτουργία προγραμματιστή** → ενεργοποίηση (ζητά επανεκκίνηση).
4. Στείλε το `.ipa` στο iPhone (AirDrop ή Αρχεία). Στο AltStore → **My Apps → +** και διάλεξέ το.
5. Όσο το AltServer τρέχει στο Mac και είστε στο ίδιο Wi-Fi, το AltStore ανανεώνει την εφαρμογή αυτόματα.

### Β. Με Xcode
1. Εγκατάστησε το Xcode και το XcodeGen (`brew install xcodegen`), και τρέξε `cd ios && xcodegen`.
2. Άνοιξε το `Oikonomika.xcodeproj`. Στο **Signing & Capabilities** διάλεξε το Apple ID σου (Personal Team). Αν σου πει ότι το bundle id είναι πιασμένο, άλλαξέ το.
3. Σύνδεσε το iPhone, ενεργοποίησε τη Λειτουργία προγραμματιστή και πάτα ▶︎.
4. Την πρώτη φορά: **Ρυθμίσεις → Γενικά → VPN & διαχείριση συσκευών** → εμπιστοσύνη στον προγραμματιστή.
5. Κάθε 7 ημέρες πάτα ξανά ▶︎.

Με λογαριασμό Apple Developer (99 $ τον χρόνο) η εφαρμογή μένει μόνιμα, μέσω TestFlight.

## Apple Pay → αυτόματη καταγραφή
Συντομεύσεις → Αυτοματισμός → **+** → **Συναλλαγή** → κάρτες → **Εκτέλεση αμέσως** → ενέργεια **Καταχώρηση πληρωμής**, με Ποσό = *Είσοδος συντόμευσης → Ποσό* και Έμπορος = *Είσοδος συντόμευσης → Έμπορος* (όχι «Πρόχειρο»).

## Ανάπτυξη
- `SpendingCore/`: η λογική (budget, μοίρασμα, περίοδοι, αντίγραφα ασφαλείας). Τα tests τρέχουν με `swift test` (χρειάζεται Xcode).
- `App/`: το SwiftUI UI.
- Σε κάθε push, το GitHub Actions κάνει build και βγάζει `.ipa`, και τρέχει την εφαρμογή σε simulator με screenshots. Ένα tag `ios-vX.Y.Z` δημιουργεί Release με το `.ipa`.
